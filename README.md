# 一起点 (YiQiDian) · 麦当劳朋友向点餐助手

> 2026 麦当劳程序员创意开发大赛参赛作品（基于麦当劳中国 MCP）
> 官方活动仓库：https://github.com/M-China/mcd-developer-innovation-challenge

和朋友**扫码一起点**麦当劳时，自动告诉你**谁爱点啥、谁踩过雷、这个月点了几次**，还能在会话里**"抢"朋友的优惠券**——但抢到本次不能用、被抢会通知对方，真要用时强制只能点他爱吃的给自己。

## 痛点
1. **朋友洞察**：自己知道爱吃什么，但朋友不在身边、要一起点外卖时，还得挨个问。→ 自动推荐朋友的常点 / 避雷 / 本月次数。
2. **抢券**：自己常没券，朋友有券却很少用。→ 在「一起点」会话内"抢"朋友的券，带明确代价与透明度。

## 功能
- **朋友常点**：基于各自历史订单频次推荐 Top3
- **朋友避雷**：朋友明确不喜欢的 + 评分过低的餐品
- **朋友本月次数**：轻量社交梗 + 提醒
- **抢券（招牌功能）**：五条机制——只在一起点内抢 / 不可叠加 / 抢到本次不可用 / 被抢通知对方 / 用时强制只点朋友爱吃的给自己
- **AA 分账**：会话内实时算账，结算给结账人

## 技术架构
「一起点」是一层**架在麦当劳 MCP 之上的朋友协调层**：
1. 每个朋友在自己手机把**自己的 MCP Token** 连进同一个 Skill 会话（扫码进 session = 各自授权）
2. Skill 在会话层**聚合**所有人的常点 / 避雷 / 券，生成合并推荐与点单方案
3. 真正下单、用券、付款仍各自在自己账号完成（AA 在会话里算好）

> 麦当劳 MCP 按个人 Token 授权，本 Skill 改不了麦当劳后台；朋友数据在会话内现采现用，不碰对方账号。

## 本地运行演示（无需 Token）
```bash
python src/together_order.py
```
使用内置 mock 数据，演示「朋友洞察」聚合与「抢券」五条机制的判断逻辑。

## 接入麦当劳 MCP
1. 前往 https://open.mcd.cn/mcp ，手机号登录 → 控制台 → 激活 → 复制 Token。
2. 将 Token 写入环境变量 `MCD_MCP_TOKEN`（见 `mcp-config.example.json`，切勿硬编码真实 Token）。
3. 在 WorkBuddy 的「连接器」中按上述 JSON 配置并启用 `mcd-mcp`。
